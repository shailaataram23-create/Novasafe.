How NovaSafe Works Under the Hood

1
Active Screen Locker (Under 10ms) Uses Android native TYPE_APPLICATION_OVERLAY to freeze the touch screen immediately when payment intents or APK installer dialogs appear.
2
Emergency Bounce Logic If dismissed or canceled, NovaSafe fires Intent.CATEGORY_HOME, minimizing the application to the launcher so money cannot be debited.
3
Native System App Lock & Zero Spying Protected by Android's built-in Biometrics against uninstalls. Requires 0 camera, 0 microphone, and 0 location permissions—the green privacy dot never turns on.
